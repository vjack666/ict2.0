## Cómo usar este índice

### Actualizar después de cada tarea

```bash
# 1. Completar tarea
cd /path/to/ICT SYSTEM
# [ejecutar trabajo]

# 2. Registrar en .hermes-worklog/
# nombre: YYYY-MM-DD_HHMM_NOMBRE_PLAN.md

# 3. Actualizar .hermes-index.md
# (añadir fila a "Bitácoras completadas" con link)

# 4. Commit
git add .hermes-worklog/ .hermes-index.md .hermes-state/
git commit -m "chore(hermes): registrar bitácora [TAREA_NAME]"
git push origin main
```

### Buscar hallazgos

```bash
# Hallazgos de hoy
ls -lrt .hermes-worklog/ | tail -5

# Buscar anomalía específica
grep -r "anomalía\|ERROR\|PAUSA" .hermes-worklog/

# Ver bloqueos resueltos
grep -A 5 "PAUSA\|resuelto" .hermes-worklog/*.md

# Commits de una tarea
git log --oneline | grep "TAREA_NAME"
```
