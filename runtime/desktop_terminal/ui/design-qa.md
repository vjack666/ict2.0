# Design QA — opción 1

Estado: PASS para la entrega local. Referencia: primera imagen seleccionada
explícitamente por el usuario en esta tarea.

Se verificó en navegador el layout oscuro institucional, navegación horizontal,
instrumento a la izquierda, gráfico central e inspector a la derecha. Se probó
cambio de pestañas, temporalidades H4/M1/M15, zoom, biblioteca y lectura de documentos.
Captura final: reports/desktop_terminal/market-final.png (raíz del repositorio).
Comparación visual realizada mostrando referencia y captura final juntas.

Iteraciones corregidas: inspector demasiado alto, etiquetas de zonas solapadas,
y error de gráfico eliminado al cambiar pestañas. Se compactó el inspector,
limitó la anotación a cuatro zonas canónicas activas/parcialmente mitigadas y
se corrigió el ciclo de vida del gráfico. Consola final sin errores.

Se revisaron vistas de escritorio 1280x720 y 1440x1024. CSS incorpora adaptación
para anchos menores; no se declara una auditoría completa de dispositivos móviles.
Los datos ilustrativos de múltiples símbolos, calendario y confianza de la imagen
se reemplazan por EURUSD, eventos y evidencia real disponible. No se inventan
noticias, señales ni probabilidades para reproducir el mockup.

corresponden a la cuenta observada. No se enviaron órdenes en la revisión visual.
